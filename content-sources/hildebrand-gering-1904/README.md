# Old Norse text: Hildebrand–Gering (1904)

Transcribed from *Die Lieder der älteren Edda (Sæmundar Edda)*, edited by Karl
Hildebrand, revised by Hugo Gering, 2nd edition (Paderborn: Schöningh, 1904).
Bellows says he based his 1923 translation on this text, so stanza numbers and
order match it with one exception (see below). The book is in the public domain
(Hildebrand died 1875, Gering died 1925). Scan:
https://archive.org/details/dieliederderlte00hild

## How it was made

Each page was read from the page images and checked word by word against three
independent OCR scans of the same edition (Toronto ×2, NYPL/Google). Words where
the transcription and all three OCR texts disagreed were rechecked on the page
image. Only the poem text is transcribed; the critical apparatus is not.

## File format

```
<stanza number>
<long line, with the caesura marked by |>
><short line (indented in the book)>
```

Editorial marks are kept as printed:

- `[ ]` lines the editor considers later additions
- `† ` a word the editor considers corrupt
- `................` lines lost in the manuscript

## Alignment with Bellows

Bellows follows this edition's numbering throughout, except that he swaps
Hávamál 88 and 89 (his note to stanza 88 explains why). The import script maps
his 88 to this text's 89 and vice versa.

## Orthography

The edition uses a normalized Old Norse spelling: þ inside words where modern
Icelandic has ð, ǫ (o with ogonek), ǫ́, ø, ǽ, and the older forms *es* (for
*er*), *vas* (for *var*), *of/umb* (for *um*).
